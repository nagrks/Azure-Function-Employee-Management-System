# GitHub Repository Creation & Push Instructions

## Problem Encountered
The GitHub repository `https://github.com/nagrks/employee-management-function` does not exist yet.

## Solution - Create Repository on GitHub

### Step 1: Create Repository on GitHub.com
1. Go to **https://github.com/new**
2. Fill in the form:
   - **Repository name**: `employee-management-function`
   - **Description**: "Azure Function HTTP Trigger with MySQL Employee Management System"
   - **Visibility**: Select "Public" or "Private"
   - **DO NOT** initialize with README, .gitignore, or license (we already have these)
3. Click **"Create repository"**

### Step 2: Push Your Code

After creating the repository, run these commands:

```powershell
cd d:\dotnet\repos\MyProjFolder

# Verify remote is set correctly
git remote -v

# If needed, update the remote URL (use your token for authentication)
# git remote set-url origin https://YOUR_USERNAME:YOUR_TOKEN@github.com/nagrks/employee-management-function.git

# Push to GitHub
git push -u origin main
```

### Step 3: Using Personal Access Token (if push fails with 403/404)

If you get an authentication error:

1. **Generate GitHub Personal Access Token**:
   - Go to https://github.com/settings/tokens
   - Click "Generate new token" → "Generate new token (classic)"
   - Select scope: ✓ `repo` (Full control of private repositories)
   - Copy the generated token

2. **Update Git Remote with Token**:
   ```powershell
   cd d:\dotnet\repos\MyProjFolder
   git remote set-url origin https://nagrks:YOUR_TOKEN_HERE@github.com/nagrks/employee-management-function.git
   ```
   Replace `YOUR_TOKEN_HERE` with the token you just created

3. **Try Push Again**:
   ```powershell
   git push -u origin main
   ```
