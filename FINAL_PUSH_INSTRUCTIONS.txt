## To Push to GitHub

### Option 1: HTTPS with Personal Access Token (Recommended for Windows)

1. **Create GitHub Personal Access Token**:
   - Go to https://github.com/settings/tokens
   - Click "Generate new token" → "Generate new token (classic)"
   - Select scopes: `repo` (Full control of private repositories)
   - Copy the token

2. **Add GitHub Remote**:
   ```powershell
   cd d:\dotnet\repos\MyProjFolder
   git remote add origin https://YOUR_GITHUB_USERNAME:YOUR_TOKEN@github.com/YOUR_GITHUB_USERNAME/YOUR_REPO.git
   ```
   Replace:
   - `YOUR_GITHUB_USERNAME` - Your GitHub username
   - `YOUR_TOKEN` - The token you just created
   - `YOUR_REPO` - Your repository name (e.g., `MyProjFolder` or `employee-management-function`)

3. **Verify Remote**:
   ```powershell
   git remote -v
   ```

4. **Push to GitHub**:
   ```powershell
   git branch -M main
   git push -u origin main
   ```

### Option 2: SSH (If you have SSH key set up)

```powershell
git remote add origin git@github.com:YOUR_GITHUB_USERNAME/YOUR_REPO.git
git branch -M main
git push -u origin main
```

### Option 3: GitHub CLI (Easiest if installed)

```powershell
# Make sure you're authenticated with GitHub CLI
gh auth login

# Create and push repository
gh repo create MyProjFolder --public --source=. --remote=origin --push
```
