### Project Setup Instructions

#### Prerequisites
1. MySQL Server installed and running on localhost:3306
2. .NET 8.0 SDK installed
3. Azure Functions Core Tools installed

#### Database Setup
1. Create the MySQL database:
   ```sql
   CREATE DATABASE ems;
   ```
2. Run the setup.sql script:
   ```bash
   mysql -u root -p ems < setup.sql
   ```
3. Update connection string in MyHttpTrigger.cs if needed

#### Build & Run
1. Restore NuGet packages: `dotnet restore`
2. Build project: `dotnet build`
3. Start function: `func start`
4. Test endpoints with Postman or curl

### Security Considerations
- All database queries use parameterized statements to prevent SQL injection
- Connection string should be moved to Azure Key Vault for production
- Implement proper authentication/authorization for API endpoints
- Use environment variables for sensitive configuration
